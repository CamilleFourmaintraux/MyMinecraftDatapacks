# Easy Renewable Sand And Gravel

A tiny data pack that adds three shapeless crafting recipes to convert between sand, red sand and gravel:

- **3 Gravel + 1 Sand (or 1 Red Sand) → 4 Gravel**
- **3 Sand + 1 Gravel (or 1 Red Sand) → 4 Sand**
- **3 Red Sand + 1 Sand (or 1 Gravel) → 4 Red Sand**

All three work in the 2×2 inventory grid, the crafting table and the crafter.

## Why "easy" renewable?

Sand, red sand and gravel are already renewable in vanilla, but not in a convenient way:

- **Sand** and **red sand** can only be renewed by buying them from Wandering Traders, who don't always offer them and only sell small amounts.
- **Gravel** can be renewed by bartering with Piglins.

This pack doesn't create any block out of nothing: each recipe gives back exactly as many blocks as you put in. It simply lets one block turn into another, one for one, as long as you already have three of the block you want.

As a result, any source of one of these blocks becomes a source of the other two. A Piglin bartering farm can now supply sand and red sand, and a stack of sand from a Wandering Trader can become gravel or red sand.

## Installation

1. Download `EasyRenewableSandAndGravel.zip`.
2. Put the zip (do not extract it) in your world's `datapacks` folder, or add it from the "Data Packs" screen when creating a world.
3. Run `/reload` if the world is already open.

## Recipe IDs

- `easyrenewablesandandgravel:convert_to_gravel`
- `easyrenewablesandandgravel:convert_to_sand`
- `easyrenewablesandandgravel:convert_to_red_sand`
